How x402 Works
01
Request
Agent calls endpoint — no payment header yet
→
02
402 Response
Server returns payTo address, asset, amount required
→
03
Sign & Pay
Agent pays on-chain or signs EIP-3009 transferWithAuthorization
→
04
Retry
Agent retries with X-Payment: <base64 payload>
→
05
Verify + Serve
Server verifies and settles payment → 200 OK + data

Integration — Base USDC clients

Use the included MCP client for Base USDC EIP-3009 payment with a 0.01 USDC default per-call cap. This server uses a JSON x402 v1 challenge; check other SDK versions before mainnet use.

MCP · Base USDC EIP-3009 
# Install the MCP client and signing dependency
npm install -g @x402-api/mcp-server viem

# Set a dedicated Base wallet key with USDC
export X402_WALLET_PRIVATE_KEY=0xYOUR_PRIVATE_KEY

# Start MCP; default payment cap is 0.01 USDC per call
x402-api-mcp

# In your MCP-capable agent, call get_crypto_prices, scan_yields, etc.
# The API must advertise EIP-3009 settlement.
Shell — Manual 402 flow 
# Step 1: Probe — get payment requirements (returns 402)
curl -s https://x402-api.fly.dev/api/price-feed | jq .

# Response: 402 Payment Required
{
  "x402Version": 1,
  "error": "Payment Required",
  "accepts": [{
    "scheme": "exact",
    "network": "base",
    "asset": "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
    "payTo": "0x60264c480b67adb557efEd22Cf0e7ceA792DefB7",
    "maxAmountRequired": "1000"
  }]
}

# Step 2: Pay on-chain or sign EIP-3009 transferWithAuthorization
# use a compatible client; do not submit raw txHash unless legacy proof is enabled

# Step 3: Retry with X-Payment header (base64 JSON payload)
curl -s https://x402-api.fly.dev/api/price-feed \
  -H "X-Payment: <base64-encoded-payment-payload>" | jq .data.core

# Response: 200 OK — live crypto prices

TypeScript · Two paid reads 
import { x402ApiRequest } from '@x402-api/elizaos-plugin';

const config = { walletPrivateKey: process.env.X402_WALLET_PRIVATE_KEY };
const funding = await x402ApiRequest<{
  arb_opportunities: Array<{ spread_bps: number }>
}>('/api/funding-rates', { asset: 'ETH' }, config);
const gas = await x402ApiRequest<{
  data: Record<string, { gas_price_gwei: { normal: number | null } }>
}>('/api/gas-tracker', {}, config);

console.log('Indicative spread:', funding.arb_opportunities[0]?.spread_bps ?? 'none');
console.log('Arbitrum gas:', gas.data.arbitrum?.gas_price_gwei.normal ?? 'unavailable');
// Fees and basis risk are excluded. Total API charge: 0.009 USDC.
